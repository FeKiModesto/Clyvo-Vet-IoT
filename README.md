# CLYVO VET — Sistema de Triagem IoT

Projeto desenvolvido para o Challenge FIAP 2026 em parceria com a Clyvo Vet.

## Sobre o Projeto
Sistema de triagem veterinária doméstica utilizando ESP32,
que auxilia o responsável pelo pet a identificar o nível
de risco do animal através de perguntas guiadas.

## Componentes Utilizados
- ESP32
- LCD 16x2 (I2C)
- 3 LEDs (Verde, Amarelo, Vermelho)
- 2 Push Buttons
- Resistores 220Ω e 10kΩ
